# Application code review

Inspect repository instructions and documented commands. Report findings by
severity with file evidence, impact, and correction. Check duplicated backend
logic and UI components, hard-coded mutable configuration, API boundaries,
tests, health checks, and container configuration. Implement fixes only when
requested.
